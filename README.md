# SelcaBooth Frame Catalogue

Public website: https://aswath17.github.io/selcabooth-frame-catalogue/

80 frame previews, including nine new keychain designs. Browse categories, search, save favourites and preview background colours for customisable frames.

This repository contains rendered preview images and minimal browsing metadata only. Original layout data, holder coordinates, source artwork and generation tools are maintained separately in a private source repository. Rendered previews are visible and downloadable as part of the public website. Artwork rights remain with their respective owners.

GitHub Pages serves `main` → `/docs`.
